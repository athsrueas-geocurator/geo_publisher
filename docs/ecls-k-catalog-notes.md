# ECLS-K:2011 catalog publication notes

## Identity and source boundary — 2026-09-12

The source catalog identifies the **Early Childhood Longitudinal Study, Kindergarten Class of 2010-11 (ECLS-K:2011)** as an NCES longitudinal cohort from kindergarten entry in 2010 through spring 2016 fifth grade. It provides public-use child-level files, documentation, and setup files, while restricted files require a license. The catalog’s uses are weighted early-childhood context, developmental trajectories, and program-participation context; it explicitly says that the data do not replace an experimental early-childhood evaluation.
